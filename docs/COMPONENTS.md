# Components Map — CSR Partnership Radar

Keep this file current whenever a component is added, changed or removed.

**Status key:** ✅ built · 🟡 partial / minimal · ⬜ not built (TODO)

**Where things run:**
- **GitHub Actions** runs two scheduled workflows:
  - `ingest.yml`, daily at 00:30 UTC (06:00 IST): live feeds, then classify, score, the 12-month archive crawl and stats.
  - `history.yml`, weekly on Sunday at 21:30 UTC (Monday 03:00 IST): news-archive history, headline classification and stats.
- **Vercel** only reads from the database. No crawling and no LLM calls happen inside Vercel request handlers.
- **Manual, about once a year:** import the National CSR Portal report. The portal is behind a CAPTCHA, so the CSV is downloaded by hand.

## Data flow

```
LIVE (daily)
RSS feeds ─► Source adapter ─► raw_items ─► Pre-filter ─► Gemini classifier ─► classifications
 (config)    (robots, rate      (by URL)     (CSR/policy    (strict JSON, zod,     (content_hash +
              limit, paging)                  keywords)      key fallback)          prompt version)
                                                                   │
                         companies ◄── Entity resolver ◄───────────┘
                                                                   │
                                Scoring (rules, config) ─► signals ─► Digest page (/)
                                                                   └─► company_news (dated, typed)

HISTORY
National CSR Portal CSV ─► history:import ─► companies (62k official names) + csr_spend (FY2014-25)
CSR news WP archives ─► history:news ─► company_news ─► history:classify-news (80 headlines/call)
csr_spend + company_news ─► history:stats ─► company_stats (history + forecasts + timing)
                                              └─► /companies/[id] profile · /planner
```

## Look and feel

**v3 (glass):** glassmorphism panels over a warm, light-filled backdrop (soft colour blobs and a light beam), a floating glass icon rail (bottom bar on phones), Outfit display + Nunito body, and an original flat illustration of diverse people in overlapping device frames (`PeopleFrames`). Secondary pages keep the valley scene as a rounded inset.

**v2:**

`app/components/illustrations.tsx` draws original inline-SVG scenes in two styles: flat CSR vector art (globe, sprouting leaves, people on dashed orbits, growth arrows, gears, water drops) and a painterly valley (sky, drifting clouds, layered hills, a village, a big tree). Motion is CSS-only (clouds drift, bubbles float, gears turn, the orbit dashes travel). It turns off under `prefers-reduced-motion`, and the scene switches to a night palette in dark mode. Fonts: Fredoka (display) and Nunito (body). Chart colours are validated for colour-blind separation and contrast in both modes (teal / orange series, blue sequential ramp), and every chart has a table view.
