# CSR Partnership Radar

A weekly CSR intelligence digest for an education NGO: new CSR initiatives, allocation increases, NGO partner searches and CSR policy changes in education, skill development, digital literacy and youth employment. Each item ends in a decision: **Call this week**, **Watch** or **Background**.

- AI: Google Gemini Flash only (REST API).
- App: Next.js (App Router) + TypeScript on Vercel. It only reads from the database.
- Data: Postgres on Neon via Drizzle ORM.
- Ingestion: TypeScript scripts in `scripts/ingest/`, run daily by GitHub Actions.

See [docs/COMPONENTS.md](docs/COMPONENTS.md) for the components map.

_Setup instructions are added as the pipeline lands._
